# Blockchain-Based Cloud Storage System

A secure, decentralized cloud storage application built using blockchain technology for enhanced security, transparency, and data integrity.

## Features
- **Decentralized Storage**: Files are encrypted and stored across a decentralized network.
- **Enhanced Security**: Blockchain ensures data is tamper-proof.
- **Cross-Platform Mobile App**: Client application built with Flutter for iOS and Android.

## Project Structure
- `cloud_storage_frontend/`: The Flutter client application.
- `cloud-storage-fyp/`: Backend services and blockchain infrastructure.

## Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install)
- iOS Simulator or Android Emulator
