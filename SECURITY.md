# Security Policy

## Supported Versions

Please ensure you are using the latest version of the application for the best security and stability.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0.0| :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Security is a top priority for our decentralized storage system. If you discover a vulnerability, we would like to know about it so we can take steps to address it as quickly as possible.

Please report vulnerabilities by opening an issue on our repository or contacting the maintainers directly. Do not disclose the vulnerability publicly until a fix has been released.
